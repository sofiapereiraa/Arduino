# 🔧 Projetos Arduino

Este repositório contém três projetos desenvolvidos com Arduino para prática de eletrônica básica e programação.

---

## 🚦 Semáforo Automático  
Simulação de um semáforo com troca automática entre os sinais.

---

## 💡 Sequenciador de LEDs  
Sistema que alterna diferentes estados de LEDs a cada clique de um botão.

---

## 🌙 Sensor de Luz (LDR)  
Projeto que detecta a intensidade de luz ambiente e controla um LED automaticamente.
