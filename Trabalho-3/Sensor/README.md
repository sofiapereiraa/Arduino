# 💡 Projeto Arduino — LDR com LED

Projeto usando Arduino com sensor LDR para detectar luz ambiente e controlar um LED automaticamente.

## ⚙️ Componentes
- Arduino UNO  
- LDR (fotoresistor)  
- LED  
- Resistor para o LED  
- Resistor para o LDR  
- Protoboard e jumpers

## 🔌 Ligações
- LDR → A0  
- LED → pino 2
